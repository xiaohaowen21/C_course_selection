# C Course Selection

一个用 C 语言实现的控制台学生选课系统课程设计项目，支持学生和管理员两种身份登录，并提供基础的选课、退课、课程管理和学生管理功能。

## 项目简介

本项目的核心代码位于 [`选课系统/course_system.c`](./选课系统/course_system.c)，程序启动后会读取本地文本数据，构建课程、学生和管理员信息，并通过命令行菜单完成交互操作。

这个项目更适合作为 C 语言课程设计、结构体与数组练习、文件读取与控制台菜单程序的学习示例。

## 已实现功能

### 学生端

- 查看全部课程
- 查看本人已选课程
- 按课程编号选课
- 按课程编号退课
- 退出当前登录

### 管理员端

- 查看全部课程
- 查看课程详情及已选学生
- 添加课程
- 删除课程
- 修改课程信息
- 查看全部学生信息
- 添加学生
- 删除学生
- 修改学生信息
- 为指定学生选课
- 为指定学生退课
- 查看管理员信息
- 退出当前登录

## 运行方式

### 编译后运行

如果你的电脑安装了 GCC / MinGW，可以在 `选课系统` 目录下执行：

```powershell
gcc .\course_system.c -o .\course_system.exe
.\course_system.exe
```

如果你使用的是其他编译器，例如 Visual Studio 的 `cl`，也可以按对应命令自行编译。

## 数据文件格式

程序启动时会读取以下三个文本文件：

### `course.txt`

第一行为表头，后续每行格式如下：

```text
课程编号 课程名称 任课教师 最大人数
```

示例：

```text
1001 高等数学 张教授 50
1002 大学物理 李教授 45
```

### `student.txt`

第一行为表头，后续每行格式如下：

```text
学号 姓名 密码
```

示例：

```text
20210001 张三 123456
20210002 李四 123456
```

### `admin.txt`

第一行为表头，后续每行格式如下：

```text
账号 姓名 密码
```

示例：

```text
10001 管理员1 admin123
10002 管理员2 admin123
```

## 程序规则

- 每个学生最多可选择 `10` 门课程。
- 课程有人数上限，满员后不能继续选课。
- 不允许重复选择同一门课程。
- 管理员可以直接为学生执行选课和退课操作。
- 删除课程时，会同步把该课程从所有学生的已选课程列表中移除。
- 删除学生时，会同步减少其已选课程的人数统计。

## 当前实现限制

- 当前版本只在启动时读取文本文件，运行过程中的修改只保存在内存中。
- 程序退出后，新增课程、删改学生、选课结果都不会自动写回到文本文件。
- 课程名、教师名、姓名等字段通过带宽度限制的 `scanf` 读取，不支持带空格的输入，超出长度的部分会被截断。
- 输入校验较基础，如果输入类型和程序预期不一致，可能出现异常行为。
- 项目目前主要面向 Windows 控制台环境。
